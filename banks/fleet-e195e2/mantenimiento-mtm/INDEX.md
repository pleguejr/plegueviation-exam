# Índice de Capítulos ATA — Manual de Mantenimiento E190/E195-E2 (MTM)

Fuente oficial: manuales/MTM.pdf (5.372 páginas, Embraer S.A. Line and Base Course T1+T2).

Este directorio (anks/fleet-e195e2/mantenimiento-mtm/) queda preparado para albergar los futuros bancos de preguntas técnicas de mantenimiento organizados por capítulos ATA:

## Capítulos ATA Indexados

| ATA | Capítulo / Sistema | Descripción |
| :--- | :--- | :--- |
| **ATA 21** | **AIR CONDITIONING** | Distribución cabina/cockpit, ventilación compartimentos electrónicos, presurización, packs de refrigeración, control de temperatura y ozono. |
| **ATA 22** | **AUTO FLIGHT** | Piloto automático (AP), Flight Director (FD), Autothrottle (AT), modos de guiado y servos. |
| **ATA 23** | **COMMUNICATIONS** | VHF, HF, interfonos, CVR, audio panels (ACP), ACARS, transponders y SELCAL. |
| **ATA 24** | **ELECTRICAL POWER** | Generación AC (IDG, APU GEN, RAT), DC (TRUs, baterías, SPDA 1 y 2, MAU), barras esenciales y distribución eléctrica. |
| **ATA 25** | **EQUIPMENT / FURNISHINGS** | Asientos de tripulación técnica y cabina, galleys, equipos de emergencia y LOPA. |
| **ATA 26** | **FIRE PROTECTION** | Detección y extinción en motores, APU, bodegas de carga FWD/AFT, lavabos y bahías electrónicas. |
| **ATA 27** | **FLIGHT CONTROLS** | Mandos de vuelo Fly-by-Wire (FBW), Primary Flight Control Units (PFCU), elevadores, timón de dirección, alerones, spoilers, flaps y slats. |
| **ATA 28** | **FUEL** | Tanques alares y central, bombas colectoras y de eyector (ejector pumps), crossfeed, válvulas de corte y reabastecimiento a presión. |
| **ATA 29** | **HYDRAULIC POWER** | Sistemas hidráulicos 1, 2 y 3 (EDP, ACMP, PTU), acumuladores y shutoff valves. |
| **ATA 30** | **ICE AND RAIN PROTECTION** | Antihielo de alas y tomas de motor por aire sangrado (bleed), calentamiento eléctrico de sondas ADS/pitot/TAT y parabrisas, limpiaparabrisas. |
| **ATA 31** | **INDICATING / RECORDING SYSTEMS** | Pantallas DU (MFD/PFD), EICAS, FDR, Central Maintenance System (CMS) y avisos aurales. |
| **ATA 32** | **LANDING GEAR** | Tren principal y de morro, extensión/retracción normal y de emergencia, frenos de carbono, autobrake, antiskid y nose wheel steering (NWS). |
| **ATA 33** | **LIGHTS** | Iluminación interior (cockpit, cabina, emergencias) y exterior (taxi, takeoff, landing, strobes, logo, wing inspection). |
| **ATA 34** | **NAVIGATION** | ADIRU/IRS, GPS/GNSS, VOR, ILS, DME, Radar meteorológico, EGPWS/TAWS, TCAS y Radioaltímetros. |
| **ATA 35** | **OXYGEN** | Sistema de oxígeno de tripulación (botella presurizada de 1850 psi) y generadores químicos para pasaje (PSU). |
| **ATA 36** | **PNEUMATIC** | Sistema de sangrado de aire (Bleed Air) de motores y APU, válvulas PRSOV, crossbleed y detección de fugas (Overheat/Leak detection). |
| **ATA 38** | **WATER / WASTE** | Agua potable presurizada y sistema de vacío para residuos de lavabos. |
| **ATA 44** | **CABIN SYSTEMS** | Sistemas de entretenimiento a bordo (IFE) y control de cabina de pasajeros. |
| **ATA 45** | **CENTRAL MAINTENANCE SYSTEM** | Central Maintenance Computer (CMC), diagnósticos, BITE test y descargas de fallos. |
| **ATA 46** | **INFORMATION SYSTEMS** | Servidores de datos y conectividad a bordo. |
| **ATA 47** | **INERT GAS SYSTEM (OBIGGS)** | Sistema de gas inerte con nitrógeno para inertización de tanques de combustible. |
| **ATA 49** | **AIRBORNE AUXILIARY POWER (APU)** | APU Pratt & Whitney APS2600, FADEC del APU, generador eléctrico y sangrado de aire. |
| **ATA 50** | **CARGO & ACCESSORY COMPARTMENTS** | Compartimentos de carga delantero y trasero, redes de contención y revestimientos. |
| **ATA 52** | **DOORS** | Puertas de pasajeros, servicio, salidas de emergencia sobre alas, compuertas de carga y puerta de cabina de vuelo. |
| **ATA 53-57** | **AIRCRAFT STRUCTURES** | Fuselaje, barquillas de motor, estabilizadores horizontal/vertical, ventanillas y alas. |
| **ATA 71-80** | **POWERPLANT (PW1900G)** | Motores turbofán Geared Turbofan (GTF), FADEC dual-channel, sistemas de combustible de motor, ignición, arranque neumático y lubricación. |
